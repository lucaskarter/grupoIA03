## 📜 Descrição

O projeto Vanguardia é um jogo educacional que cria uma experiência imersiva utilizando elementos narrativos para promover a exploração e uso do raciocínio lógico com o objetivo de ensinar sobre os conceitos de inteligência artificial, sendo desenvolvido para diminuir as taxas de evasão e aumentar o engajamento de jovens universitários com cursos online que abordam esses conceitos. 

No Vanguardia, o jogador assume o papel de Sophia, uma cientista que é congelada para auxiliar a humanidade caso haja problemas extremos envolvendo aplicações tecnológicas no futuro; ao ser necessário, ela tem ajuda de Asimov, um robô criado por uma equipe para auxiliar a cientista, em sua missão de amparar a humanidade após o mal uso da Inteligência Articial. Assim, Sophia tem que aprender sobre os conceitos de IA a partir de ensinamentos do Asimov e atividade práticas sobre diferentes tópicos.

Durante o jogo, o jogador aprende e trabalha conceitos de Aprendizagem de Máquina, funcionamento de Redes Neurais Artificias, coleta, separação e limpeza de dados e aplicações éticas da IA a partir de mini-games  para que o usuário aplique os conceitos observados durante o projeto. O projeto auxilia para que o aprendizado e fixação dos conteúdos de Inteligência Artificial se torne um processo dinâmico, facilitando e tornando o aprendizado mais participativo e envolvente.

## 📁 Estrutura de pastas

Dentre os arquivos e pastas presentes na raiz do projeto, definem-se:

- <b>assets</b>: aqui estão os arquivos relacionados a elementos não-estruturados deste repositório, como imagens.

- <b>documents</b>: aqui estão todos os documentos do projeto, como o Game Development Document (GDD) bem como imagens complementares, na pasta "assets".

- <b>src</b>: Todo o código fonte criado para o desenvolvimento do projeto do jogo.

- <b>README.md</b>: arquivo que serve como guia e explicação geral sobre o projeto e o jogo (o mesmo que você está lendo agora).

## 🔧 Como executar o código

#### Instalação básica

Para configurar o projeto, certifique-se de ter as versões mais recentes dos seguintes softwares:

- **Navegador web** (Google Chrome, Mozilla Firefox, Safari, etc.) com suporte a HTML5 e JavaScript.
- **Git**, disponível para download <a href="https://git-scm.com/">aqui</a>.
- **Visual Studio Code**, que pode ser baixado <a href="https://code.visualstudio.com/">aqui</a>.
- **Extensão Live Server** para o VS Code. Instale-a pela aba de extensões (ícone de quadrado na barra lateral esquerda) pesquisando por "Live Server" e escolhendo a versão de "ritwickdey".
- **Node.js**, disponível para download <a href="https://nodejs.org/pt">aqui</a>.

#### Execução do jogo

1. **Clonar pasta para o VS Code:**

- No GitLab Web, selecione a opção "Code" > "Clone with HTTPS" e copie o link exibido.

- Crie uma pasta ou selecione uma já existente na sua máquina e abra com Git Bash.

- No terminal do Git Bash, digite "git clone + link copiado".

- Digite "code ." no terminal para abrir o arquivo no Visual Studio Code.

2. **Rodar projeto:**

- No Visual Studio Code, abra o arquivo index.html.

- Clique com o botão direito sobre o arquivo e selecione "Open with Live Server".

- O jogo será carregado no seu navegador.

Para abrir diretamente o index.html clique <a href="">aqui</a>.

#### Método alternativo

Caso necessário, utilize a seguinte opção:

**Baixar o arquivo ZIP:**

- No GitLab Web, vá em "Clone" e localize o ícone de Download (próximo ao botão Web IDE).

- Selecione a opção zip.

- Extraia os arquivos e abra a pasta no Visual Studio Code.

- Clique com o botão direito sobre o arquivo e selecione "Open with Live Server".

- O jogo será carregado no seu navegador.
